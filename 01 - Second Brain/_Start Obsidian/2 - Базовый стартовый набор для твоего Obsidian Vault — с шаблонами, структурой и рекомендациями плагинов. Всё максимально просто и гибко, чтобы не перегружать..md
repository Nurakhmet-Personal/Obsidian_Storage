## 📁 Структура Vault'а (папки)

```
/00_Входящие        ← сюда можно писать "всё подряд" 
/01_Дневник         ← ежедневные заметки 
/02_Мысли           ← идеи, наблюдения, инсайты 
/03_Проекты         ← всё, что требует действий 
/Templates          ← шаблоны
```


> ⚠️ Названия с префиксами (`00_`, `01_`) помогают сортировать папки вручную.

---
## 📄 Шаблоны для `/Templates`

1. **daily.md** — шаблон для ежедневных заметок

```
# <% tp.date.now("DD.MM.YYYY") %>

## ☀️ Утро
- Настроение:
- Цель на день:

## 🌙 Вечер
- Что получилось:
- Что запомнилось:
- Мысли/выводы:
```

---

2. **idea.md** — шаблон для мыслей

```
# 💡 <% tp.file.title %>

## Идея
<Краткое описание>

## Контекст
<Как пришла идея, зачем>

## Следующий шаг
<Нужно ли что-то делать?>
```

---

3. **project.md** — шаблон для проекта

```
# 📌 <% tp.file.title %>

## Цель
<Что хочу достичь>

## Следующие шаги
- [ ] Задача 1
- [ ] Задача 2

## Связанные заметки
- [[...]]
```
